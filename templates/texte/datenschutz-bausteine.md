# Textentwurf: Bausteine für die Datenschutzerklärung (Art. 13 DSGVO)

**Entwurf – keine Rechtsberatung, vor Veröffentlichung prüfen lassen.**

So verwenden Sie diese Bausteine:
- Nur die Bausteine übernehmen, die auf Ihre Website zutreffen. Blöcke mit „[Nur wenn …:]“ nur übernehmen, wenn die Bedingung zutrifft.
- Platzhalter in eckigen Klammern ersetzen. Rechtsgrundlagen, Speicherdauern und Übermittlungsgrundlagen **nicht raten**, sondern beim Anbieter bzw. in Ihren Verträgen nachsehen und prüfen lassen.
- Für **jeden** auf der Website eingebundenen Drittdienst (Analyse, Karten, Videos, Schriftarten, Newsletter-Dienst, CAPTCHA usw.) einen eigenen Baustein 3 anlegen. Dienste, die die Website nicht mehr nutzt, aus der Erklärung entfernen.
- Die Bausteine ersetzen keine vollständige Datenschutzerklärung. Empfehlung: anwaltliche Prüfung oder Generator eines seriösen Anbieters.

## Baustein 4: Schriftarten

### Schritt zuerst: Schriftarten lokal einbinden (kein Text für die Erklärung)
Werden Schriftarten (z. B. Google Fonts) beim Seitenaufruf von fremden Servern geladen, erhält der Anbieter die IP-Adresse der Besucher. Empfohlene Abhilfe:
1. Schriftdateien (z. B. im Format woff2) herunterladen und auf dem eigenen Server ablegen.
2. Im CSS bzw. Theme alle Verweise auf `fonts.googleapis.com` und `fonts.gstatic.com` (oder andere Schrift-Server) durch die eigenen Dateien ersetzen (`@font-face` mit lokaler `src`).
3. `preconnect`-Hinweise auf fremde Schrift-Server entfernen.
4. Bei WordPress: auch Theme- und Plugin-Einstellungen prüfen, die Schriften nachladen.
5. Nach der Umstellung erneut prüfen, ob noch Anfragen an fremde Schrift-Server gehen.

### Textbaustein (nur nach lokaler Einbindung)
Diese Website verwendet Schriftarten, die auf unserem eigenen Server gespeichert sind. Beim Laden der Schriftarten wird keine Verbindung zu Servern Dritter aufgebaut.
